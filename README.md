# 🇮🇳 Bharat Mitra AI

> **Your Personal Civic & Rights Assistant for Every Indian**

Bharat Mitra AI is an AI-powered citizen assistance platform designed to bridge the gap between citizens and public services. The platform enables users to discover government schemes, report civic issues, understand their legal rights, and receive personalized assistance through a conversational, multilingual interface.

Built with accessibility and inclusivity at its core, Bharat Mitra AI empowers citizens through voice-first interactions, AI-driven guidance, and intelligent automation.

---

## 🌟 Vision

Millions of Indians struggle to access government benefits, understand legal rights, and navigate public services due to language barriers, digital complexity, and fragmented systems.

**Bharat Mitra AI simplifies public service access by acting as a single intelligent assistant that listens, understands, guides, and takes action on behalf of citizens.**

## ⚙️ Installation

### Prerequisites

* Node.js v16+
* MongoDB (Local or Atlas)
* npm or yarn

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/bharat-mitra-ai.git

cd bharat-mitra-ai
```

---

### 2️⃣ Setup Backend

```bash
cd backend

npm install
```

Create a `.env` file:

```env
PORT=5000

MONGO_URI=mongodb://127.0.0.1:27017/bharatMitra
```

Start the backend server:

```bash
npm start
```

or

```bash
node index.js
```

---

### 3️⃣ Setup Frontend

```bash
cd frontend

npm install

npm run dev
```

Open:

```text
http://localhost:5173
```
